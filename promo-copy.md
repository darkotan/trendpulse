版本1（实在型）：
────────────────
Title: I built a real-time dashboard that aggregates HN, stocks, crypto, and GitHub trending — no ads, no signup

Body:
I got tired of checking 4 different sites every morning, so I built TrendPulse.

It pulls live data from:
- Hacker News top stories
- Stock market movers (Yahoo Finance)
- Crypto prices (Binance)
- GitHub trending repos

All on one page. Auto-refreshes every 5 minutes. Works on mobile.

Built with Python/Flask, zero API keys needed — all public APIs.
No ads, no signup, just data.

https://trendscan.org

Would love feedback on what data sources to add next.

版本3（技术型）：
────────────────
Title: I built a zero-dependency data aggregator with Flask + vanilla JS

Body:
TrendPulse aggregates Hacker News, Yahoo Finance, Binance, and GitHub APIs into a single dashboard.

Interesting bits:
- All data fetched via Python stdlib (urllib), no requests/httpx
- Server-side cache with background refresh thread
- Vercel-inspired CSS design system
- Full i18n (English/Chinese auto-detect)
- Cloudflare Tunnel for zero-config deployment

Source and site: https://trendscan.org

Built this in a few hours with AI assistance. Curious what data sources you'd add.
